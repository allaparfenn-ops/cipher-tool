# Шифры — учебное приложение

Простой старт проекта на **Python + PySide6 + QML (Qt Quick Controls)**.
Вкладки «Цезарь», «Виженер», «XOR», «Атбаш» и «Аффинный».
У каждого шифра свои разделы «Практика» и «Теория» со своей справкой.
Интерфейс и комментарии на русском.

Сейчас работает шифр Цезаря: шифрование и расшифровка, выбор русского
или английского алфавита, готовый пример, очистка и пояснение первых 12 замен.
Регистр сохраняется, русский алфавит включает Ё. Символы вне выбранного
алфавита остаются без изменения. Для расшифровки вставьте шифротекст
в исходное поле и выберите тот же алфавит и сдвиг.

## Запуск в Windows (PowerShell)

Нужен Python 3.10 или новее. Выполните в папке проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Активировать окружение не обязательно: команды используют его Python напрямую.

## Как устроен код

- `main.py` — создаёт приложение, передаёт объект Python в QML, открывает окно.
- `ciphers.py` — обычная Python-функция шифра Цезаря, независимая от Qt.
- `backend.py` — рабочий метод `process_caesar` и заготовки
  `process_atbash`, `process_vigenere`, доступные QML через `@Slot`.
- `qml/Main.qml` — окно и вкладки пяти шифров.
- `qml/CipherPage.qml` — общая структура разделов «Практика» и «Теория».
- `qml/CaesarPage.qml` — справка Цезаря и подключение его практики.
- `qml/CaesarPractice.qml` — рабочая форма Цезаря: ввод, кнопки и результат.
- `qml/VigenerePage.qml`, `qml/XorPage.qml`, `qml/AtbashPage.qml`,
  `qml/AffinePage.qml` — собственные справки и заготовки практики остальных шифров.
- `qml/CipherPlaceholder.qml` — общее оформление заготовок.
- `qml/TheoryPage.qml` — общее оформление справки, текст приходит со страницы шифра.

Путь одного действия: кнопка в QML → `backend.process_caesar(...)` → `caesar(...)`
→ словарь с результатом и пояснением → текстовые поля в QML.
Для знакомства с проектом удобно читать файлы в порядке:
`ciphers.py`, `backend.py`, `main.py`, затем QML.

## Пример использования

Проверка интерфейса: нажмите «Пример» с английским алфавитом и сдвигом 3.
Ожидаемый результат: `Khoor, zruog!`. Перенесите его во входное поле
и нажмите «Расшифровать»: получится `Hello, world!`.

## Дальнейшие шаги

Чтобы реализовать один из подготовленных шифров:

1. Добавьте функцию алгоритма в `ciphers.py`.
2. Добавьте метод с `@Slot` в `backend.py` для вызова из QML.
   Для Атбаша и Виженера уже есть заготовки с параметрами и комментариями.
   Пока они возвращают пустой результат и сообщение «не реализован».
3. Замените `CipherPlaceholder` внутри `practiceComponent` нужного шифра
   на форму по примеру `CaesarPractice.qml`. Вкладка уже подключена.
   Его справка редактируется в свойстве `theoryText` той же страницы.

Чтобы добавить ещё один шифр, создайте страницу на основе `CipherPage`
со своими `practiceComponent` и `theoryText`. Добавьте
`TabButton` и страницу в `StackLayout` в `Main.qml` на одинаковых
позициях. Введённый текст Цезаря сохраняется при переключении вкладок.

Кандидаты: Цезарь, Виженер, XOR, Атбаш и аффинный шифр.
Реализован только Цезарь. История, анимация, частотный анализ, сравнение,
сохранение в файл и темы оформления оставлены на следующие этапы.
